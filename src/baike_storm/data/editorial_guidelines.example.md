## 体育人物

**目录骨架(8 节)**:人物简介 → 运动生涯 → 主要成绩 → 技术特点 → 训练与团队 → 场外活动 → 争议与评价 → 社会影响

### 1. 人物简介

写清楚出生信息、所属项目、代表队或俱乐部与职业起点。时间线要精确到年。

### 2. 运动生涯

按时间梳理训练经历、职业阶段、重要赛事与角色变化,注明资料来源。

### 3. 主要成绩

按赛事和年份罗列可核验的名次、纪录、奖项或荣誉,注明统计口径。

### 4. 技术特点

介绍公开资料中有明确依据的技术风格、战术特点或比赛表现,避免无依据的比较。

### 5. 训练与团队

介绍教练、队友、训练方式和团队协作,只使用公开可核验的信息。

## 电子产品

**目录骨架(9 节)**:发展历史 → 产品规格 → 产品设计 → 核心技术 → 产品型号 → 营销与销售 → 相关事件 → 市场反响 → 产品文化

### 1. 发展历史

从产品线肇始到当前迭代的完整时间线,标注每个关键版本年份。

### 2. 产品规格

参数表:尺寸、重量、屏幕、芯片、电池、接口等,数字必须与官方一致。

### 3. 核心技术

解释产品采用的核心技术原理(如屏幕驱动、芯片架构),面向普通读者通俗说明。

### 4. 市场反响

引用销量、市占率、媒体评测与用户口碑,注明统计口径与时间。

## 自然地理

**目录骨架(10 节)**:形成演变 → 地理环境 → 气候特点 → 自然资源 → 生物资源 → 历史人文 → 旅游开发 → 保护措施 → 相关文化 → 外部链接

### 1. 形成演变

地质构造、演化历史与成因机制,引用地质年代。

### 2. 地理环境

位置、范围、地形地貌、水文特征;可配数据表格。

### 3. 气候特点

气候类型、气温与降水统计(注明统计年份区间)。

### 4. 生物资源

代表性动植物物种,标注学名与保护等级。

### 5. 旅游开发

开发历程、主要景区、客流数据(注明统计口径)。
