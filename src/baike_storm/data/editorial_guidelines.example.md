# 百科编辑指南示例(editorial_guidelines.example)

> 本文件是**格式示例**:演示如何按「词条大类 → 目录骨架 / 写作要点」提供编辑指南。
> 真实使用时可替换为完整版线上指南(数百个细类),格式保持 `## 大类名` + `**目录骨架(N 节)**:…` 即可,
> 解析器会自动按 `## ` 分段、提取骨架行,并把整段当作写作要点提示喂给生成器。
> 未提供该文件时,流水线仅少一个「同类参考」提示,流程不受影响。

## 人物

**目录骨架(8 节)**:人物生平 → 主要成就 → 人物作品 → 个人生活 → 社会活动 → 人物争议 → 人物评价 → 人物影响

### 1. 人物生平

写清楚出生年月日、籍贯、家庭背景、求学经历与职业起点。时间线要精确到年。

### 2. 主要成就

按领域或时间罗列核心成就,给出可量化的结果(奖项名称、年份、数据)。

### 3. 人物作品

列代表作品(著作/影视/音乐等),注明发表或上映时间。

### 4. 人物争议

如存在争议,客观陈述各派观点与事实核对结果,不做价值判断。

### 5. 人物评价

引用权威媒体、同行或官方机构的评价,注明出处。

## 电子产品

**目录骨架(9 节)**:发展历史 → 产品规格 → 产品设计 → 核心技术 → 产品型号 → 营销与销售 → 相关事件 → 市场反响 → 产品文化

### 1. 发展历史

从产品线肇始到当前迭代的完整时间线,标注每个关键版本年份。

### 2. 产品规格

参数表:尺寸、重量、屏幕、芯片、电池、接口等,数字必须与官方一致。

### 3. 核心技术

解释产品采用的核心技术原理(如屏幕驱动、芯片架构),面向普通读者通俗说明。

### 4. 市场反响

引用销量、市占率、媒体评测与用户口碑,注明统计口径与时间。

## 自然地理

**目录骨架(10 节)**:形成演变 → 地理环境 → 气候特点 → 自然资源 → 生物资源 → 历史人文 → 旅游开发 → 保护措施 → 相关文化 → 外部链接

### 1. 形成演变

地质构造、演化历史与成因机制,引用地质年代。

### 2. 地理环境

位置、范围、地形地貌、水文特征;可配数据表格。

### 3. 气候特点

气候类型、气温与降水统计(注明统计年份区间)。

### 4. 生物资源

代表性动植物物种,标注学名与保护等级。

### 5. 旅游开发

开发历程、主要景区、客流数据(注明统计口径)。
